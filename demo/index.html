01 · WHAT JUST HAPPENED

Claude wrote the SQL. The connector ran it.

You asked in plain English. Claude turned that into a query, and the connector ran it against a read-only copy of the database. Only SELECTs are allowed, every query is logged, and results are capped. Then instead of pasting 50 rows of text, the connector handed back a panel.

Open "SQL that produced this" under any result to see exactly what ran.

02 · WHY IT MATTERS

Your people stay in the tool they already use.

No new dashboard to learn, no export to Excel. Sales asks about an account and gets the account. Support asks what's stuck and gets the list, clickable. Finance asks for revenue by region and gets a chart. Same connector, same rules, in the chat window they already have open.

The panel is yours to design. Tables and charts here, but it can be a map, a form, an approval button, whatever the job is.

03 · TRY IT FOR REAL

Run this connector in your own Claude Desktop.

The whole thing is open source with a seeded sample database. No API key needed. Clone it, point Claude Desktop at it, ask it something.

git clone https://github.com/WillisK-0/ask-your-data
cd ask-your-data && npm install && npm run seed

Then add it in Claude Desktop under Settings › Developer › Edit Config. The README has the snippet. Swap the SQLite adapter for Postgres or SQL Server and it's your data.
